# v0.2 financial document pipeline

Introduces EventBridge routing, Standard Step Functions, text and scanned-image intake, a versioned Nova Micro extraction prompt, Pydantic validation, conditional DynamoDB claims and checkpointed publication. Deploy through the AWS Console or SAM. The first live session exercises eight uploads with retry, review and duplicate checks.
