# v0.1

Implemented: synthetic UTF-8 invoice processing from S3 through Lambda and
Bedrock Converse, strict schema/date/currency/string/line-item/Decimal arithmetic
validation, JSON output, correlated errors, bounded reads, version-aware source
fetching, retry failure destination, SAM configuration and mocked unit tests.

Local acceptance: pytest, SAM lint and SAM build. Live acceptance requires prior
approval: deploy, upload valid/invalid examples, inspect extracted fields and
traces, verify IAM/event delivery/model access/logs/failure routing, then clean up.
Local fixtures do not measure real extraction accuracy or operational impact.

Out of scope: PDFs, OCR, UI, discounts, credit notes, FX, due dates, production
SLAs, exactly-once invocation, accuracy benchmarks and automatic deployment.
Supported currencies and arithmetic rules are in README.md.

## AWS implementation workflow

Deploy template.yaml from CloudShell using docs/deployment.md, run the real
scripts/verify_aws.py smoke test, then scripts/cleanup_aws.py per docs/cleanup.md.
See docs/costs.md for explicitly assumed costs. Nova Micro is the default model.
Unit tests remain optional regressions, separate from live verification.
